Setup & Installation

Clone the repository, copy the environment file, install dependencies, and start the server.

cp .env.example .env
npm install

# Development
npm run dev

# Production
npm run build && npm start

Home

GET /api/home
Returns featured, latest episodes, trending, and recently updated content.
{
  "success": true,
  "cached": false,
  "data": {
    "featured": [...],
    "latestEpisodes": [...],
    "trending": [...],
    "recentlyUpdated": [...]
  }
}
📺

Anime List

GET /api/anime?page=1
Paginated list of all anime available on the platform.

Query Parameters

ParamTypeDefaultDescription
page number 1 Page number for pagination

Response

{
  "success": true,
  "data": [...],
  "pagination": {
    "currentPage": 1,
    "hasNextPage": true,
    "hasPrevPage": false,
    "totalPages": 10,
    "pages": [1, 2, 3, 4, 5, 10]
  }
}
🎌

Anime Detail

GET /api/anime/:slug
Get full anime detail including all seasons and episodes. Optionally filter by season.

Variants

GET /api/anime/:slug
GET /api/anime/:slug?season=2

Query Parameters

ParamTypeDefaultDescription
season number latest Filter episodes by season number

Response

{
  "success": true,
  "data": {
    "title": "Jujutsu Kaisen",
    "slug": "jujutsu-kaisen",
    "seasons": [
      { "name": "Season 1", "number": 1, "episodeCount": 24 },
      { "name": "Season 2", "number": 2, "episodeCount": 23 },
      { "name": "Season 3", "number": 3, "episodeCount": 12 }
    ],
    "currentSeason": { "name": "Season 2", "number": 2, "episodeCount": 23 },
    "episodes": [
      {
        "title": "Hidden Inventory",
        "number": "S2E1",
        "season": "Season 2",
        "seasonNumber": 2,
        "url": "...",
        "slug": "..."
      }
    ],
    "totalEpisodes": 23
  }
}

Search

GET /api/anime/search?q=naruto&page=1
Search anime by title keyword with optional pagination.

Query Parameters

ParamRequiredDescription
q required Search query string
page optional Page number
🎭

By Genre

GET /api/anime/genre/:genre?page=1
Filter anime by genre slug with pagination support.

Example

GET /api/anime/genre/action?page=2

Use the /api/genres endpoint to retrieve all available genre slugs.

🌐

Video Extraction

GET /api/video?url=<episode_url>
Extract video stream URL from an episode URL or slug.

Variants

GET /api/video?url=<episode_url>
GET /api/video/:slug

GET /api/health
Check the operational status of the API server.
API is operational · All systems normal

Pagination

All list endpoints return a pagination object. Use pages for numbered buttons and hasNextPage/hasPrevPage for NEXT/PREV navigation.

{
  "currentPage": 2,
  "hasNextPage": true,
  "hasPrevPage": true,
  "totalPages": 10,
  "pages": [1, 2, 3, 4, 5, 10]
}
